## 1. הגדרת הבעיה

### 1.1 הקשר ומשתמש היעד
האפליקציה מיועדת לאנשים עם ADHD וקשיי זיכרון — מי שנזכר בדברים חשובים ברגעים
אקראיים ואין לו דרך מהירה ופשוטה ללכוד אותם לפני שנשכחים.

> **ADHD Expert:** שלושה כשלים ליבתיים — Working Memory (מחשבה נעלמת תוך שניות),
> Prospective Memory (התכוונות בלי ביצוע), ודיסרגולציה אנרגטית (חלונות מוטיבציה
> קצרים וסגירות ממושכות).

### 1.2 הכאבים המרכזיים

| כאב | תיאור |
|-----|-------|
| לכוד מהיר | עד שמוצאים איפה לרשום — הדבר כבר נשכח |
| פיזור בכלים | משימות בוואטסאפ, נייר, Notes — אין מקום מרכזי |
| קיטלוג ידני | לחשוב "לאן זה שייך?" בזמן לחץ — מכשול |
| Inbox Anxiety | ריבוי פריטים לא ממוינים יוצר בושה ומשתק |
| חוסר סגירת לופ | לכידה בלי ביצוע = אשפה. אין מסלול ברור ל"טופל" |
| ממשק מורכב | taxonomy מורכב = overhead קוגניטיבי = נטישה |
| רעיונות שנשכחים | רעיון לפיתוח נרשם בגליון אקראי ונשכח — אין תיקייה ייעודית שמחזירה אותו |
| משימות בלי תיעדוף | המון משימות עבודה פזורות — לא ברור מה קודם, מה הושלם, מה נשאר |
| רשימת קניות חלקית | עוברים על הרשימה ושוכחים מה כבר בעגלה — אין הבדל ויזואלי בין "לקחתי" ל"עדיין צריך" |

**הצהרת הבעיה:**
> "כשאני נזכר במשהו, אין לי דרך פשוטה מספיק ללכוד אותו ברגע שבו אני נזכר.
> עד שאני מוצא איפה לרשום — זה כבר אבד."

## 2. מטרות ויעדים

### 2.1 חזון המוצר
אפליקציה אחת שמאפשרת ללכוד כל מחשבה בקול / טקסט / מצלמה / רשימה ולמיין
אוטומטית — ללא מאמץ קוגניטיבי. מיועדת מהיסוד לאנשים עם ADHD.

> **ADHD Expert:** המטרה האחת הקריטית — הפחתת חיכוך ועומס קוגניטיבי בכל נקודת
> מגע. אפליקציה שנראית מאורגנת אבל דורשת יותר קוגניציה מאשר חוסכת — לא תעבוד.

### 2.2 מטרות המוצר

| מטרה | פירוט |
|------|-------|
| לכידה תוך 3 שניות | 4 כפתורי לכידה זמינים מיידית — ללא בחירת קטגוריה בזמן הלכידה |
| Zero Friction | הפעולה המרכזית בלחיצה אחת מכל מצב — widget, נעילת מסך, Siri shortcut |
| סיווג אוטומטי | AI מסווג, מציע. אישור בטאפ אחד. Triage רק אם confidence < 75% |
| Graceful Degradation | האפליקציה שימושית גם אחרי 3 ימי היעדרות — בלי הצפה ובלי עונש |
| סגירת לופ | כל פריט יש לו מסלול ברור מ"נלכד" ל"טופל" — מדד ההצלחה האמיתי |

### 2.3 מה לא ב-v0.1
- שיתוף עם משתמשים אחרים
- סנכרון לענן / גיבוי
- אינטגרציה עם Google Calendar
- הגדרות אבטחה ופרטיות
- Gamification / ניקוד (להימנע — עלול להגביר חרדה)

## 3. משתמשים ופרסונות

### 3.1 המשתמש העיקרי — שחר
אדם שמתמודד עם ADHD ובעיות זיכרון. נזכר בדברים ברגעים בלתי צפויים — בנסיעה,
בין פגישות, לפני שינה.

**צרכים עיקריים:**
- ללכוד מחשבה לפני שהיא נשכחת — בפחות מ-5 שניות
- לדעת שהדבר "שמור" — אישור חושי מיידי (haptic + אנימציה)
- לראות בבוקר 3-5 דברים — לא 47
- לא לחוש אשמה כשלא נכנס 3 ימים
- מסלול ברור מ"נלכד" ל"בוצע"

**הרגלים:** מעדיף דיבור על פני הקלדה; מצלם דברים שרוצה לזכור; חלונות קצרים של
אנרגיה גבוהה — חייב לנצל אותם.

> ציטוט: "אם זה לוקח יותר מ-5 שניות — אני לא אעשה את זה."

## 4. עקרונות עיצוב — ADHD-First

### 4.1 חמישה עקרונות ליבה

| עיקרון | יישום באפליקציה |
|--------|------------------|
| Zero-Friction Capture | לכידה בלחיצה אחת מכל מצב. ללא בחירת קטגוריה בזמן הלכידה. הכל עובר ל-inbox תחילה |
| Visual Simplicity | מסך בית עם פעולה ראשית אחת בולטת. לא יותר מ-5 קטגוריות ראשיות. צבעים פונקציונליים בלבד |
| Positive Reinforcement | Haptic (40ms) + checkmark שמתמוסס (800ms) בכל שמירה. "נשמר" — לא "אשר" |
| Contextual Reminders | תזכורות לפי מיקום GPS, לפי pattern, לפי הקשר — לא רק שעון |
| Graceful Degradation | אחרי 3 ימי היעדרות: "AI מיין בשבילך. יש לך 3 דברים שצריכים אותך." לא 47 unread |

### 4.2 Progressive Disclosure — מה נחשף מתי

| Tier | מה מוצג ומתי |
|------|---------------|
| Tier 1 — פתיחה ראשונה | 4 כפתורי לכידה בלבד + FAB. שום תיקיות, שום הגדרות. Empty state: "מה אתה רוצה לזכור היום?" |
| Tier 2 — אחרי פריט ראשון | סרגל ניווט תחתון מופיע. תיקיות נחשפות לראשונה |
| Tier 3 — אחרי 5 פריטים | כפתור "Smart Sort" — הצעה לארגן פריטי Unsorted |
| Tier 4 — 7+ ימים | הגדרות AI, קטגוריות מותאמות, bulk operations, brain dump mode |

### 4.3 שלוש טעויות שאסור לעשות

| טעות | הפתרון הנכון |
|------|---------------|
| Confirm לפני שמירה | Undo Toast (4 שניות) במקום Modal אישור. המשתמש סומך שנשמר |
| Triage לפני שהמידע קיים | Triage תמיד אחרי הלכידה, לא תוך כדי — לא לנתק את הזרימה |
| Empty State שובר מורל | "אין פריטים" ללא הנחיה = כישלון. להציג 4 כפתורי לכידה בולטים יותר |

## 5. פיצ'רים

### 5.1 ארבע דרכי לכידה
4 כפתורים גדולים שווים במסך הבית. ניתן לגשת לכולם גם דרך Widget ממסך הטלפון.

**קול (Voice Capture)** — FAB בלחיצה ממושכת. גל אנימציה — לא טיימר. תמלול חי
תוך 1.5 שניות. לחיצה ארוכה = מקליט, שחרור = עצירה. שמירה אוטומטית אם AI בטוח;
Triage רק אם לא.

**טקסט (Text Input)** — שדה טקסט פתוח עם placeholder דינמי: "מה רצית לזכור?".
Auto-save אחרי 3 שניות — אינדיקטור "נשמר" שקט. ‎#hashtag ידני לסיווג מהיר ללא
triage.

**מצלמה (Camera Capture)** — OCR + Object Detection מיידי. ממשק "crop + confirm"
מינימלי.

| מה מצלמים | מה קורה |
|-----------|---------|
| מוצר (חלב, שמפו) | AI מזהה → "להוסיף לרשימת קניות?" → כפתור ירוק גדול |
| רשימה כתובה | OCR קורא, מפצל לפריטים, מוצג לאישור לפני שמירה |
| מסמך / קבלה | OCR מחלץ טקסט → סיווג → שמירה בתיקייה |
| מוצר לרכישה עתידית | "לשמור ב-רצון לקנות?" + הצעה לחפש מחיר |
| תמונת השראה | AI מציע תיקיית תחביב / השראה לפי תוכן |
| כרטיס ביקור | חילוץ שם + טלפון + מייל → משימה / איש קשר |

**רשימה ידנית (Manual List)** — שורה אחת לכל פריט, Enter יוצר שורה חדשה (ללא
כפתור "הוסף"). בחירת יעד בכפתורי קיצור: קניות / משימות / רעיונות / תיקייה.
AI מפצל אוטומטית אם יש פריטים מסוגים שונים. "הוסף" — לחצן אחד, הכל נשמר.

### 5.2 Smart Triage — ניווט היררכי בטאפים
Bottom Sheet ב-30% מסך. מופעל רק כש-confidence < 75%.

| שלב | תיאור |
|-----|-------|
| טריגר | AI לא בטוח (confidence < 75%) — Bottom Sheet עולה אוטומטית |
| שלב 1 — תחום | שורת טאפים גדולים: עבודה \| בית \| בריאות \| תחביבים \| אחר |
| שלב 2 — תת-קטגוריה | Sheet מתרחב: קניות \| ילדים \| תיקונים \| חשבונות (לפי בחירה) |
| שלב 3 — AI מציע | "לשמור כמשימה?" / "להוסיף לרשימה?" — אישור / שינוי |
| Escape תמידי | "שמור ללא קטגוריה" זמין בכל שלב |
| Timeout | אם המשתמש מתעלם 5 שניות — נשמר ב-Unsorted, Sheet נסגר |
| Learning | אחרי 3 בחירות דומות — AI עולה ל-auto mode לאותו תוכן |

### 5.3 מבנה תיקיות היררכי

| תחום ראשי | תת-קטגוריות |
|-----------|--------------|
| עבודה | משימות / פגישות / פרויקטים / רעיונות עסקיים |
| בית | קניות / ילדים / תיקונים / חשבונות |
| בריאות | תרופות / פגישות רופא / כושר |
| תחביבים | השראה / רצון לקנות / מתכונים / ספרים |
| Unsorted / כללי | פריטים ממתינים לסיווג — תמיד גישה מהירה |

### 5.4 פיצ'רים ADHD-Specific

| פיצ'ר | תיאור |
|--------|-------|
| Smart Daily Digest | כל בוקר: 3-5 הפריטים הדחופים ביותר — ה-AI בחר, לא המשתמש |
| Brain Dump Mode | מקליט / מקליד ברצף בלי עצירות — AI מפרק אוטומטית לפריטים נפרדים |
| Friction-Free Snooze | "תזכיר כשאני בבית" / "מחר בבוקר" — שתי נגיעות בלבד |
| Weekly Sweep | שאלה שבועית על פריטים ישנים: "עדיין רלוונטי?" + Swipe מהיר למחיקה |
| Completion Ritual | בסימון "בוצע" — אנימציה קצרה + haptic. מחזק קשר לכידה → סגירה |
| Recurring Detection | AI מזהה pattern חוזר → מציע להפוך לרוטינה (לתרופות, לקניות שבועיות) |

### 5.5 Micro-Interactions — פידבק חושי

| Interaction | פירוט |
|-------------|-------|
| שמירה מוצלחת | Checkmark קטן שמתמוסס תוך 800ms + Haptic 40ms |
| Category Tag | תווית קטגוריה "מחליקה" מתחת לפריט 0.5 שניות אחרי שמירה |
| Undo | Toast בתחתית המסך, 4 שניות. "בוטל" — לא Modal |
| AI מעבד | Ring spinner עדין סביב FAB — לא מסך חסימה |
| פריט נכנס לתיקייה | Folder icon מוגדל רגע ומצטמצם — המשתמש רואה לאן הלך |
| Completion | פריט "נמחק" בסוויפ עם אנימציה + haptic כפול |

### 5.6 מודול א — תיקיית רעיונות לפיתוח
כאב ליבה: רעיון לאפליקציה, לפיצ'ר, לפרויקט — צץ ונעלם.

- משתמש מדבר: "יש לי רעיון לאפליקציה שמ..." — AI מזהה את הפתיחה ומסווג לתיקיית
  רעיונות לפיתוח.
- תיקייה ייעודית: אפליקציות, פיצ'רים, פרויקטים, שיפורים, גימיקים.
- כל רעיון נשמר עם תמלול מלא + תאריך + tag אוטומטי (אפליקציה / פיצ'ר / עסק / יצירה).
- דפדוף בכל זמן — ממוינים לפי תאריך / tag / לא-טופל.

| מצב | תיאור |
|-----|-------|
| לכידה | קול → AI מזהה "זה רעיון" → נכנס לתיקייה אוטומטית |
| תצוגה | כרטיסיות לפי tag: אפליקציות \| פיצ'רים \| עסקי \| יצירתי |
| העשרה | AI מוסיף שאלות: "האם חשבת על: מה הכאב שהוא פותר?" |
| הזזה | אפשר להעביר רעיון ל"בפיתוח" כשהחלטת לפעול |
| Swipe | ימינה = מעניין / שמאלה = לא רלוונטי יותר |

### 5.7 מודול ב — מנהל משימות עם תיעדוף
כאב ליבה: המון משימות עבודה, לא ברור מה קודם, לא ברור מה הושלם.

- כל משימה חדשה נכנסת לפול; AI מציע עדיפות (דחוף / היום / השבוע / אחר כך).
- תצוגה ממוינת תמיד מעדיפות גבוהה לנמוכה — לא לפי סדר הזנה.
- משימה שהושלמה — Swipe ימינה → Completion Ritual → ארכיון.
- ארכיון גלוי: "מה עשיתי השבוע" — מחזק תחושת הצלחה.

| שדה | תיאור |
|-----|-------|
| שם משימה | טקסט חופשי, מתמלול קולי |
| עדיפות | AI מציע: דחוף / היום / השבוע / אחר כך — ניתן לשנות |
| סטטוס | פתוח / בביצוע / הושלם / בוטל |
| תאריך יעד | אופציונלי — מזוהה אוטומטית מהקול ("עד יום שלישי") |
| ארכיון | כל משימה שהושלמה נשמרת עם timestamp |

**מסך משימות:** פס עדיפות עליון (עד 3 משימות דחופות, גדולות ובולטות); רשימת
היום (Checkbox גדול); "השבוע" מתקפל; כפתור ארכיון "מה עשיתי השבוע".

### 5.8 מודול ג — רשימת קניות חכמה עם מצב קניות
כאב ליבה: עוברים על הרשימה בסופר ושוכחים מה כבר בעגלה.

- מצב רגיל — רשימת פריטים לרכישה; מוסיפים בקול / טקסט / מצלמה.
- מצב קניות — "אני בסופר" → כל פריט מוצג גדול עם Checkbox בולט; לחיצה = הפריט
  מתעמעם לאפור בהיר + V ירוק ("בעגלה") אך נשאר ברשימה; פריטים שלא נלחצו נשארים
  לבנים ובולטים; בסיום: "כל הפריטים בעגלה!" + ניקוי לרשימה חדשה.

| פעולה | תיאור |
|--------|-------|
| הוספה | קול: "תוסיף חלב" / טקסט / מצלמת מוצר → נכנס מיידית לרשימה |
| מצב קניות | כפתור "אני בסופר" → Checkbox גדול לכל פריט |
| לחיצה על פריט | מתעמעם לאפור + V ירוק = "בעגלה" |
| לחיצה חוזרת | חוזר ללבן = "טעות, לא לקחתי" |
| סיום | "סיימתי" → "לשמור כרשימה קבועה?" → נקה |
| רשימה קבועה | פריטים חוזרים (חלב, לחם) — ניתן לטעון ברשימה חדשה בטאפ |

### 5.9 פיצ'רים עתידיים (v2+)
חיפוש קולי; Contextual Reminders לפי GPS; חיפוש מוצרים באינטרנט מהמצלמה; שיתוף
רשימות; אינטגרציית Google Calendar; מצב נוחות (גופן גדול, high contrast); AI
שמזהה רעיון חוזר ומציע לפתח אותו.

### 5.10 Daily Check-in — המזכיר האישי
פעם ביום התראה: "בוא נעבור על הבורדים". שאלה אחת קצרה לכל בורד — לא review
פריט-פריט. 30 שניות וסיים.

| בורד | שאלת ה-Check-in | תשובות אפשריות |
|------|------------------|-----------------|
| משימות | "עשית משהו? צריך לעדכן?" | הכל בסדר \| פתח ועדכן |
| קניות | "הרשימה עדכנית? יש להוסיף?" | הכל בסדר \| פתח ועדכן |
| פגישות | "הפגישה התבצעה? צריך לעדכן?" | בוצע \| עדיין קרובה \| פתח ועדכן |
| todo | "כל מה שהיה צריך — טופל?" | הכל בסדר \| פתח ועדכן |

מה לא נשאל: רעיונות / מסמכים / השראה — אוצרים, לא משימות.

**"פתח ועדכן"** פותח את הבורד הרלוונטי מיידית לעריכה ישירה, וחוזר ל-Check-in
אוטומטית אחרי סגירת הבורד.

| הגדרה | ברירת מחדל |
|--------|-------------|
| שעת ההתראה | 9:00 בוקר — ניתן לשינוי |
| בורדים שנשאלים | משימות / קניות / פגישות / todo — ניתן להתאים |
| מה לא נשאל | רעיונות / מסמכים / השראה — לעולם לא |
| משך | עד 30 שניות אם לוחצים רק "הכל בסדר" |

## 6. מסלולי משתמש (User Flows)

### 6.1 Flow 1 — Onboarding
מינימלי בהחלט — שלושה שלבים בלבד: 1) שם / כינוי 2) בחירת פרופיל: "פשוט לכוד" \|
"מאורגן" \| "עם תזכורות" 3) הוספת Widget (ניתן לדלג). מסך בית ריק: 4 כפתורי
לכידה + "מה אתה רוצה לזכור היום?". כל השאר נלמד תוך שימוש.

### 6.2 Flow 2 — הקלטת קול (הזרם המרכזי)
Widget / פתיחה → FAB → לחיצה ארוכה → גל אנימציה → דיבור → שחרור → תמלול תוך
1.5 שניות → (א) AI בטוח: Checkmark + Haptic → חזרה לבית; (ב) AI לא בטוח: Smart
Triage → 2-3 טאפים → שמירה.

### 6.3 Flow 3 — צילום מוצר לרשימת קניות
מצלמה → צילום מוצר → זיהוי תוך שנייה ("זיהיתי: חלב 3%") → "להוסיף לרשימת
קניות?" כפתור ירוק גדול → מוכן לצילום הבא מיידית.

### 6.4 Flow 4 — חזרה אחרי היעדרות
אחרי 3 ימי היעדרות: "ברוך שובך" → "AI מיין בשבילך. יש לך 3 דברים שצריכים אותך
היום." → סקירת 3-5 פריטים בלבד (Swipe = הושלם / דחה) → Weekly Sweep לפריטים
ישנים.

### 6.5 Flow 5 — Brain Dump Mode
לחיצה ארוכה > 3 שניות → מצב Brain Dump → דיבור רצוף ללא עצירה (גל אנימציה רחב
יותר) → AI מפרק לפריטים לפי הפסקות ותוכן → רשימת פריטים לאישור / מחיקה / מיזוג
→ "שמור הכל" בטאפ אחד.

### 6.6 Flow 6 — צילום מסמך → משימה עם קובץ מצורף
צילום קנס / טופס → OCR + זיהוי תוכן ("קנס עירייה") → "ליצור משימה: תשלום קנס?"
→ טאפ אחד → משימה + התמונה מצורפת → לחיצה על המשימה פותחת את התמונה מייד →
Swipe ימינה = בוצע + Completion Ritual.

דוגמאות: קנס / ארנונה → "תשלום קנס"; חשבונית חשמל → "לשלם חשבונית" + PDF;
מרשם רופא → "לקבוע תור"; רשימת קניות על נייר → פריטים נפרדים + תמונת הנייר.

### 6.7 Flow 7 — Daily Check-in
9:00 התראה → בורד משימות → בורד קניות → בורד פגישות → עריכה אם נבחר "פתח
ועדכן" → "כל הכבוד. הבורדים מעודכנים." + Completion Ritual.

## 8. סיכונים ואתגרים

### 8.1 מטריצת סיכונים

| סיכון | רמה | השפעה | מיטיגציה |
|--------|-----|--------|-----------|
| דיוק AI בסיווג | גבוה | פריטים במקום הלא נכון → אובדן אמון | Preview לפני שמירה + Smart Triage + Triage Learning |
| Onboarding ארוך | גבוה | נטישה לפני value | מקסימום 3 שלבים, Progressive Disclosure, ללא tour |
| Inbox Anxiety | גבוה | ריבוי unread = המשתמש מפסיק לפתוח | Daily Digest + Weekly Sweep + Graceful Degradation |
| זיהוי מוצרים במצלמה | בינוני | מוצר לא מזוהה = תסכול | Fallback: "לא זיהיתי — לאיפה לשמור?" |
| מהירות AI | בינוני | עיכוב > 3 שניות = נטישה | Skeleton UI + עיבוד ברקע + Spinner עדין |
| אין סגירת לופ | בינוני | לכידה בלי ביצוע = חסרת ערך | Completion Ritual + Daily Digest + Weekly Sweep |

### 8.2 נקודות בדיקה
- שבוע 1: זמן לכידה < 5 שניות? Onboarding < 60 שניות?
- שבוע 2: סיווג AI מאושר ב-80%+ ללא שינוי?
- שבוע 3: Smart Triage < 3 טאפים? Brain Dump משומש?
- חודש 1: האם פריטים נסגרים? (North Star Metric חיובי?)
- חודש 2: האם Recurring Detection מוצע ומאושר?

## 9. מדדי הצלחה — KPIs

### 9.1 North Star Metric
מספר פריטים שנלכדו **וגם** הושלמו / נסגרו באותו שבוע. לכידה בלי סגירה =
אפליקציה-מחסן. אם המספר עולה שבוע אחרי שבוע — האפליקציה עובדת.

### 9.2 מדדי ביצוע

| מדד (KPI) | יעד | שיטת מדידה | תדירות |
|-----------|-----|--------------|---------|
| זמן לכידה | < 5 שניות מפתיחה עד שמירה | Session Recording | שבועי |
| דיוק סיווג AI | > 80% ללא שינוי ידני | classification_accepted | שבועי |
| זמן Smart Triage | < 3 טאפים לסיווג | triage_steps_count | שבועי |
| שיעור מצלמה | > 25% מהלכידות | capture_source=camera | שבועי |
| שיעור סגירה | > 60% מהמשימות שנלכדו | completion_rate | שבועי |
| שימוש יומי | פתיחה 1+ פעמים ביום | app_open | יומי |
| שיעור Widget | > 30% מהלכידות | capture_source=widget | שבועי |
| Digest פתוח | > 70% מהתראות הבוקר נפתחות | notification_open_rate | שבועי |
| Weekly Sweep | > 50% מהסוויפים מובילים למחיקה/סגירה | sweep_completion_rate | שבועי |
