# Session — 2026-11-20

## Goal
Build a professional, maximally automated pipeline that produces and publishes one faceless
AI short (TikTok / YouTube Shorts / Instagram Reels) every 3 days.

## What happened
- New self-contained project `shorts-pipeline/` (Python 3.12, src layout, 26 modules, 67 tests).
- Stages behind Protocols: script (Claude structured output, `beta.messages.parse` with
  server-side fallbacks), voice (ElevenLabs with-timestamps → word timings), visuals (fal.ai
  FLUX images or Pexels portrait stock), render (ffmpeg: Ken Burns, concat, ASS word-highlight
  captions, loudnorm, 1080x1920 H.264/AAC), publish (YouTube resumable upload, Instagram Reels
  container flow, TikTok FILE_UPLOAD chunked direct post).
- Every stage has an offline mock; `shorts --mock run` renders a real MP4 in ~17 s here.
- Jobs are directories with an atomic `manifest.json`; a failed publish resumes without
  re-rendering (tested). `shorts serve` = stdlib HTTP (`/health`, `/runs`, `/media/<job>/final.mp4`
  for Instagram) + scheduler loop (due = last successful publish + N days at a preferred hour).
- Deploy: Dockerfile + railway.toml (volume at /app/data), GitHub Actions template as fallback.

## Decisions & rationale
- Subfolder in this repo, not a new GitHub repo: creating a repo is an owner gate and GitHub
  scope here is this repo only. `git subtree split` moves it later without history loss.
- Direct platform APIs over a unified posting SaaS: no monthly fee, no third party holding
  tokens; the Publisher Protocol leaves room for a unified adapter if the TikTok audit stalls.
- Stdlib HTTP server instead of FastAPI: three routes do not justify a framework dependency.
- Image generation (FLUX schnell) + Ken Burns rather than AI video generation: ~100x cheaper per
  second and the look is the proven faceless-channel style; `VisualAsset.kind="video"` already
  renders clips, so a video-gen provider is an adapter away.

## Worth remembering
- ASS colours are `&HAABBGGRR`: yellow is `&H0000D7FF`, not `&H00FFD200` (that is cyan).
- YouTube `videos.insert` now costs 1,600 quota units (default 10,000/day): ~6 uploads/day max.
- TikTok Direct Post forces SELF_ONLY until the app passes audit; Instagram needs a public
  video URL (served by the pipeline itself); both token lifetimes need external rotation.
