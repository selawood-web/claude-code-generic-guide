# Session — 2026-11-09

## Goal
Give the owner a tool and a method for CabiCAD's UI/UX problem: tools that behave
differently per board, irrelevant controls still clickable, one action reachable from
several places — architecture defects a screenshot review cannot see.

## What happened
- New skill `/ui-contract`: one JSON file (`design/ui-contract.json`) describes model,
  boards as output lenses, contexts, surfaces and commands; `tools/ui_contract_lint.py`
  checks fourteen rules (UC01–UC14) and prints a context × command matrix.
- Method: observe the running app → lint (findings are the baseline) → target contract,
  owner decisions as a pick-list → wire (app reads the contract as its command registry,
  one E2E test holds the UI to it in every context) → `/feature` per diff group.
- Companions: `contract-schema.md`, `wiring.md` (JS registry + Playwright spec),
  `example-contract.json` (four-board cabinet CAD, lint-clean). 28 tests.
- Shipped like feature_lint: install.sh, update.sh, verifier guard PY_SCRIPTS, catalogs,
  USER-MANUAL section 6, SYSTEM-OVERVIEW row.
- Attaching `SnowflakeSolutions/Cabicad` was denied by the permission classifier; the
  observe step on the real app waits on the owner.

## Decisions & rationale
- Off-board commands default to `disabled` with a generated reason ("Available in
  Manufacture"), not `hidden`: the UI teaches what exists and where.
- A command whose `does` varies by board is an error, not a warning: either the difference
  is output (belongs in the board profile) or it is a second command with its own name.
- Inside a command's own board every state must be declared (UC12): a generated reason
  there would be wrong.
- `.claude/skills/*.json` joined INSTRUCTION_GLOBS in validate.py and audit_facts.py: a
  skill tells the agent to read the example, so the scan covers it. test_audit_facts'
  "binary artifacts" test now allows .json — it is text.

## Worth remembering
- A "confusing" UI complaint is an interaction-architecture problem; the fix is a contract
  the app executes plus a test, not a design review. `/gbb` is for "feels wrong".
