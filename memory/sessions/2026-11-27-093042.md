## Decisions & rationale
- Deck claims must be grounded: a docs fact counts only when read verbatim. The fetch
  agents read about the first 40k characters of each page and summarized the rest, so
  anything resting on a summary was reworded or removed rather than asserted.
- "Deny wins" in permissions is verbatim in the docs ("deny, then ask, then allow");
  "a hook can block what an allow rule permits" was not found verbatim and was dropped.
- The charter fix is wording, not rule: the byte-stability rule stands because a value
  that changes each session pays full price for everything after it in each session.

## Worth remembering
- Subagent worktrees branch from the default branch unless `worktree.baseRef` is
  `"head"`; `.claude/settings.json` sets `head` so the audit verifier checks the commit
  under audit. Files git ignores do not exist in a worktree.
- A skill with `disable-model-invocation: true` has no description in context at all; the
  seven outward or costly skills here use it, which is also a prompt-injection defence.
- Prompt cache default lifetime is 5 minutes; a change ends the hit from that byte on.
- Doc checks through a fetch agent: ask for verbatim quotes and an UNVERIFIED mark on
  anything from the summarized remainder of a long page.
