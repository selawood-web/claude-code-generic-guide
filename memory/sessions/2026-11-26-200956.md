## Worth remembering
- The vocabulary tracks hook event names only, not handler fields like `onFailure`.
- Claude Code treats any command-hook exit other than 0 or 2, or a failed launch, as non-blocking unless `onFailure: "block"` is set (v2.1.295+, per the hooks reference).
- Since 2.1.325, scheduled tasks and `/loop` ask before running a skill that declares `allowed-tools` or hooks; `/ccgg-audit` is the only such skill here.
