# CABICAD installers app — demo

A clickable, single-file demo of a field app for installers, connected to CABICAD.
All data is invented and the CABICAD API calls are simulated.

Open `index.html` in a browser. Nothing to install or build.

Published copy (private): https://claude.ai/artifact/MDwbFpUi4bEoqTQLY5HwTR

What it shows:

- Task list grouped by day.
- Per task, three steps: customer (contact, access, coordination notes), project file
  (survey, drawings, renderings, spec, cabinets, accessory products), and handover or completions.
- Rejects: pick a cabinet, then its part from the cut list, or request a new part with a sketch.
  Fault codes, priority P1–P4 with SLA, and a manager reject board.
- A sync log that shows each action as a CABICAD API call.
