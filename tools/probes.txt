# Mutation probes against the repository's gate — the living contract of what the
# gate is known to catch. Run by tools/audit_probes.py; read by CI on every push.
#
# One probe per line:   label | expect | shell mutation
#   label     what defect is planted (free text, no pipes)
#   expect    caught  — the gate is known to fail on this defect; a miss fails CI
#             missed  — a known blind spot; a catch is reported so it can be promoted
#   mutation  a bash snippet run in a scratch copy of the tree at HEAD, before the gate;
#             exit 3 means "not applicable in this repository" and the probe is skipped
#
# A miss on a `caught` line is a regression in the gate. A catch on a `missed` line
# means a check landed: promote the line to `caught` in the same pull request.
# The first list is the 2026-09-16 audit's table; keep it sorted by kind, not by date.
